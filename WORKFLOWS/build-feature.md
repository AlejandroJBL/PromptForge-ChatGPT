# WORKFLOW: BUILD FEATURE

Usa este workflow cuando el usuario quiera diseñar o implementar una nueva funcionalidad.

## Objetivo

Convertir una idea o necesidad en una propuesta técnica e implementable, alineada con el contexto del proyecto.

## Secuencia de trabajo

### 1. Entender la funcionalidad
Identifica:
- qué se quiere construir;
- para quién;
- qué problema resuelve;
- qué restricciones existen.

Si falta información crítica, pide solo la mínima necesaria.

### 2. Revisar contexto existente
Consulta primero:
- `MEMORY/project-context.md`
- `MEMORY/product-vision.md`
- `MEMORY/tech-stack.md`
- `MEMORY/coding-standards.md`
- `MEMORY/architecture-decisions.md`

### 3. Definir alcance
Separa claramente:
- versión mínima viable;
- mejoras opcionales;
- decisiones que pueden aplazarse.

### 4. Diseñar la solución
Incluye:
- enfoque recomendado;
- componentes o módulos afectados;
- flujo de datos;
- dependencias;
- riesgos.

### 5. Preparar implementación
Si el usuario quiere ejecutar:
- lista archivos a crear o modificar;
- describe el orden de trabajo;
- entrega contenido completo cuando se solicite;
- evita cambios innecesarios fuera del alcance.

### 6. Definir validación
Incluye:
- pruebas funcionales;
- casos borde;
- validaciones manuales;
- riesgos de regresión.

## Formato de salida recomendado

1. Objetivo de la funcionalidad
2. Supuestos y restricciones
3. Diseño propuesto
4. Archivos afectados
5. Plan de implementación
6. Validación
7. Riesgos
