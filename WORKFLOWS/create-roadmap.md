# WORKFLOW: CREATE ROADMAP

Usa este workflow cuando el usuario quiera ordenar trabajo futuro en fases, hitos o prioridades.

## Objetivo

Convertir una visión general en un roadmap práctico, priorizado y coherente con el estado real del proyecto.

## Secuencia de trabajo

### 1. Entender el contexto
Aclara:
- objetivo general;
- estado actual;
- restricciones;
- plazo;
- recursos disponibles.

### 2. Identificar grandes bloques
Separa el trabajo en áreas como:
- producto;
- arquitectura;
- desarrollo;
- validación;
- documentación;
- despliegue;
- operaciones.

### 3. Priorizar
Organiza según:
- dependencia;
- impacto;
- urgencia;
- complejidad;
- riesgo.

### 4. Definir fases
Agrupa el trabajo en:
- ahora;
- siguiente;
- después;
- más adelante.

O, si conviene:
- fase 1;
- fase 2;
- fase 3.

### 5. Definir entregables
Cada fase debe tener:
- objetivo;
- tareas principales;
- criterio de finalización;
- riesgos.

### 6. Validar coherencia
Comprueba:
- que el orden tiene sentido;
- que no faltan dependencias críticas;
- que el alcance es razonable;
- que el roadmap sirve para actuar, no solo para decorar.

## Formato de salida recomendado

1. Objetivo del roadmap
2. Supuestos y restricciones
3. Fases
4. Tareas por fase
5. Riesgos
6. Recomendación de prioridad inmediata
