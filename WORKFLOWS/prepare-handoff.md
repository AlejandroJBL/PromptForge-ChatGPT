# WORKFLOW: PREPARE HANDOFF

Usa este workflow cuando el usuario quiera cerrar una sesión de trabajo dejando contexto útil para continuar después.

## Objetivo

Preparar un handoff claro, breve y accionable para una próxima sesión o para otra persona.

## Secuencia de trabajo

### 1. Resumir el estado actual
Incluye:
- qué se hizo;
- qué se decidió;
- qué quedó pendiente;
- qué riesgos siguen abiertos.

### 2. Registrar decisiones
Anota:
- decisiones cerradas;
- supuestos provisionales;
- cambios aplicados;
- archivos afectados, si aplica.

### 3. Registrar pendientes
Separa:
- siguiente acción recomendada;
- bloqueos;
- dudas;
- validaciones pendientes.

### 4. Preparar continuidad
Indica:
- qué debe leer primero la próxima persona o sesión;
- qué archivos o chats son más relevantes;
- qué contexto no debe perderse.

## Formato de salida recomendado

1. Estado actual
2. Decisiones tomadas
3. Archivos o áreas afectadas
4. Pendientes
5. Riesgos o dudas
6. Próximo paso recomendado
